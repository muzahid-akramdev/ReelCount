# ReelCount

ডিজিটাল ওয়েলবিইং: Facebook, Instagram ও YouTube-এ দিনে কতটা Reels/Shorts দেখা হয়, সেটা দৈনিক টোটাল একটা ওয়েব ড্যাশবোর্ডে সিঙ্ক হয়।

Digital wellbeing tracker that counts short videos watched per day and syncs totals to a web dashboard.

## অবস্থা

| পর্ব | কী | অবস্থা |
|---|---|---|
| Phase 1 | Android ট্র্যাকার | **প্রস্তাব অপেক্ষায় বন্ধি — কোড এখনও লেখা হয়নি** |
| Phase 2 | Supabase + সিঙ্ক | পরে |
| Phase 3 | Next.js ড্যাশবোর্ড | পরে |
| Phase 4 | ব্রাউজার এক্সটেনশন (ঐচ্ছিক) | পরে |
